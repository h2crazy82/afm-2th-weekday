## 3. 조사 내용 (Research)

### 3.1 정의
**항온항습기**는 외부 기후 조건과 무관하게 **특정 공간(또는 챔버 내부)의 온도와 습도를 설정값으로 일정하게 유지**시키는 장치. 냉각·가열·가습·제습 네 기능을 조합해 목표 온습도를 만들고, 센서 피드백으로 지속 보정.

| 구분 | 목적 | 대표 사용처 |
|------|------|-------------|
| **환경시험용 챔버** | 극한/변동 온습도 노출로 내구성·신뢰성 검증 | 반도체, 배터리, 자동차 부품, 전자·디스플레이 |
| **공간 항온항습 설비** | 실내 환경을 일정하게 유지 | 전산실·데이터센터, 수술실, 실험실, 박물관·문서보관실, 발효·숙성 |

### 3.2 작동 원리 — 4가지 기능

**냉각(Cooling)** — 냉동 사이클:
```
압축기(Compressor) → 응축기(Condenser) → 팽창밸브(Expansion Valve) → 증발기(Evaporator) → (반복)
```
- 압축기: 냉매를 고온·고압 기체로 압축
- 응축기: 열을 외부로 방출하며 냉매 액화
- 팽창밸브: 급팽창으로 저온·저압화 (전자식 EEV는 스텝모터로 과열도 PID 제어)
- 증발기(냉각 코일): 챔버 내부 공기 열 흡수 → 공기 냉각

**가열(Heating)** — 전기 재열히터 발열(SUS 핀으로 부식 방지). 압축기와 히터가 PID로 동시 동작하며 균형점 유지.

**가습(Humidification)** — 증기식(보일러/증기 발생기, 정밀) / 수 증발식 / 초음파식.

**제습(Dehumidification)** — 냉각 코일 표면을 이슬점(노점) 이하로 냉각 → 수증기가 응축·배출. 냉각과 물리적으로 연동됨.

### 3.3 제어 시스템
- **PID 제어**: 목표값 편차(P)·누적(I)·변화율(D)로 출력 조정, 오버슈트 없이 수렴
- **센서**: 온도(PT100 등 RTD), 습도(용량식)로 실시간 피드백
- **온·습도 상호간섭**: RH는 온도 종속 → 건구/습구 온도 또는 노점 함께 관리
- **안전/인터록**: 과열 방지, 저수위(가습수 부족) 경보, 압축기 과부하 보호

### 3.4 대표 사양 (고급 시험용 기준)
| 항목 | 대표값 |
|------|--------|
| 온도 범위 | -40 ℃ ~ +150 ℃ (극한형 -70 ℃급) |
| 온도 안정도 | 최대 ±0.5 ℃ |
| 습도 범위 | 20 % ~ 98 % RH |
| 습도 정확도 | ±2.0 ~ 2.5 % RH |
| 승온/강온율 | 모델별 (사이클형은 분당 수 ℃) |

### 3.5 종류
1. **정온항습형(Steady-state)** — 설정값 장시간 유지, 신뢰성·수명 테스트
2. **온습도 사이클형(Cyclic)** — 프로그램된 주기로 변동, 급변 환경 내구성 평가 (램프/소크 패턴)
3. **대용량 Walk-in형** — 사람이 들어갈 만큼 큼, 대형 시료(자동차·건축자재)
4. **(연관) 열충격·배터리 챔버** — 극단 급전환, 배터리 안전시험 특화

### 3.6 관제 UI 설계 관점
**실시간 모니터링**: 현재/목표 온도·습도, 시계열 그래프(설정값 대비 편차), 각 기능 동작·출력률(%), 노점·건구/습구 등 파생지표
**제어**: SV 입력, PID 파라미터(고급), 사이클 프로그램 편집기(램프/소크), 운전 시작/정지/일시정지
**알람·안전**: 상·하한 편차 경보, 저수위, 과열, 압축기 이상 이벤트 로그, 정상/경고/이상 색상 구분
**이력/리포트**: 데이터 로깅·CSV 내보내기, 시험 성적서 리포트
